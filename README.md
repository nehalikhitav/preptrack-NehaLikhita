# preptrack-NehaLikhita
Placement Preparation Performance Analyzer 
-----------------------------
Project Overview
---------------------
PrepTrack is a Python console-based application designed to evaluate a student's placement readiness. The system collects student information, validates inputs, records seven days of practice scores, analyzes performance, and determines placement eligibility based on predefined criteria such as attendance, average score, project completion, profile verification, and practice consistency. Finally, it generates a detailed report with the student's status, primary blocker, and recommended next action.

Features Implemented
-----------------------------
Student detail collection with input validation
Validation for attendance percentage (0–100)
Validation for Yes/No inputs
Seven-day practice score tracking
Attendance and absence tracking
Score classification:
Strong (75–100)
Satisfactory (60–74)
Needs Improvement (40–59)
Critical (0–39)
Pass/Fail calculation
Highest and lowest score identification
First critical score detection
Average score calculation
Placement eligibility evaluation based on multiple criteria
Final placement readiness report generation
Personalized blocker identification and next action recommendations

How to Run the Program
-----------------------
Prerequisites
---
Python 3.x installed on your system
Steps
---
1.Download or clone the project.
2.Open the project folder in Visual Studio Code or any Python IDE.
3.Open the terminal.
4.Run the program using:
     python main.py
5.Enter the required student details.
